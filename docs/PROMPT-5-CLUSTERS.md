# Prompt 5 — Topical Cluster Architecture

## Buyer journey

```
Discovery (products) → Research (comparisons) → Evaluate (manufacturer guides)
  → Commercial (price / export) → Climate (country) → RFQ
```

## Internal linking pattern (mandatory on refresh)

```
PRODUCT → APPLICATION/SOLUTION → TECHNICAL GUIDE → COMPARISON
  → COUNTRY/EXPORT → BUYER GUIDE → COMPANY → RFQ
```

Anchor text: descriptive (“PUF vs PIR for cold storage”), not “click here”.
